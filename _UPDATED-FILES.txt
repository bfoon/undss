UPDATED FILES — NES Studio: Agentic flows + Policy card
For bfoon/undss, against base commit df20e05. Paths mirror your project.
This package contains everything (the first Agentic flows update included),
so it can go onto a clean df20e05 or over the previous Agentic flows update.

NEW IN THIS UPDATE
  * Policy card: upload a policy as Word, PDF or text (or paste / link / reuse
    another agent's). It is read into a rulebook that lives INSIDE the agent —
    the file is not kept, and people you share or export the agent to get the
    policy built in.
  * Every document is checked rule by rule → Doesn't apply / Complies /
    Warning / Breach, and each outcome can inform, warn, hold for a sign-off,
    run another agent, start a Flow Studio workflow, or stop the run.
    A rule can carry its own action (e.g. "over USD 50,000 → start the
    Contracts Committee workflow").
  * Knowledge link cards can take an uploaded file too.
  * New ready-made agent: "Policy guard for documents I'm asked to sign".
  * New run status "Stopped by a policy" (needs makemigrations, below).

Copy in with:
    cp -r undss/. /path/to/your/undss/
or apply the patch to a clean df20e05:
    git apply agentic-flows.patch

Then:
    docker compose build web
    docker compose exec web python manage.py makemigrations accounts
    docker compose exec web python manage.py migrate
    docker compose exec web python manage.py test accounts.tests_esign_agents     # 47 tests

Everything works on the built-in offline engine. For Claude, add to
web.environment in docker-compose.yml:
    - AGENT_AI_PROVIDER=anthropic
    - AGENT_AI_API_KEY=sk-ant-...

Read docs/agentic-flows.md (section 5 is the Policy card). Delete this file
afterwards; it is not part of the project.
