Verifying without UN PASS

The evidence package is a single ASiC-E container holding the sealed document, the sealed Certificate of Completion, the full certificate chain, the revocation data, the hash-linked audit trail with its signed anchor, and a manifest of SHA-256 digests. It verifies with sha256sum and openssl alone — no network, no account, no this system. VERIFY.txt inside walks through it.

{% if public %} Download evidence package {% else %} Download evidence package {% endif %}

Sealing follows the PAdES baseline profile of ETSI EN 319 142 (also published as ISO 14533-3), so the signature is verifiable by Adobe Acrobat and any conformant validator without access to UN PASS. The audit trail is hash-linked and its head signed; the evidence package follows the ASiC-E container conventions of ETSI EN 319 162.
