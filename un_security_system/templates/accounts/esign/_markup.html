{% comment %} accounts/templates/accounts/esign/_markup.html Word-style markup layer for the eSign PDF viewers. Mounts on top of EsignPdf without touching it: the host page passes EsignMarkup.onPage as the viewer's onPage callback, so every mark is repainted on each zoom / resize redraw exactly like signature fields are. NOTE for anyone editing this header: Django's hash-comment syntax is SINGLE LINE ONLY. A multi-line block of it leaves every following line live, so an example "include this template" line inside the comment made the template include itself and blew the stack with a RecursionError. Keep prose inside this comment block, and keep template-tag syntax out of it entirely. Usage in a viewer page: 1. Include this template in the extra_js block, after the _pdf_loader include. 2. Put a
wherever the comment cards should go. 3. Call EsignMarkup.init({ pane, thread, canAnnotate, allowInternal, urls }) with urls = { list, add, reply, resolve, remove }. 4. Pass onPage: EsignMarkup.onPage to EsignPdf.createViewer, or call EsignMarkup.onPage(wrap, docId, pageNo) from your own onPage handler. URLs carrying an annotation id are built with 0 as the placeholder and the real id is swapped in client-side. {% endcomment %} {% csrf_token %}
