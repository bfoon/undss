{% comment %} templates/partials/_nav_items.html ══════════════════════════════════ The navigation link tree, written once and included twice — by the desktop sidebar and by the mobile drawer. Editing a link here changes it in both. Every permission condition is carried over unchanged from the old navbar: the same `request.tenancy_features.*` flags, the same role checks, the same `is_csm` / `is_csr_fulfiller` variables. The structural change is that three levels (navbar → dropdown → item) became two (section → item). A sidebar has the vertical room that a navbar does not, so nothing needs to hide behind a caret. `navscope` is required, and must differ between the two includes: {% include "partials/_nav_items.html" with navscope="sb" %} {# sidebar #} {% include "partials/_nav_items.html" with navscope="dw" %} {# drawer #} It prefixes every collapse id. Without it both copies would share ids, and Bootstrap targets the first match in the document — so a toggle tapped in the drawer would silently expand the group in the hidden sidebar instead. {% endcomment %}
